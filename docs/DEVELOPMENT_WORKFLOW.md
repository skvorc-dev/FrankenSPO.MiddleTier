# MiddleTier workflow

This is a **planned** project. Track M0 readiness in issue #1. Keep prerelease technical documentation correct and do not assert that a runtime or NuGet artifact exists.

Do not begin feature implementation until its required Core contracts are verified. Once active, use linked issues, focused PRs, real-provider and contract tests, human and agent documentation, compilable samples, and source-versioned feature manifests.

Keep private integrations, unreleased product names, secret material and unannounced organization details out of this public repository.
